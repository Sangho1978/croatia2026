# CROATIA 2026 MIX05

## 기준과 수정 범위
기준은 `croatia2026_mix04_github_pages.zip`입니다. 다른 프로토타입으로 교체하지 않았습니다.

- 최초: 이름 + 전화 끝 4자리. 이후: 저장된 이름이 나오면 로그인 버튼만 누릅니다. 자동 진입은 하지 않습니다.
- 기존 MIX04에서 성공한 로그인 이름도 그대로 이어받습니다. 비밀번호 원문은 새로 저장하지 않습니다.
- 로그아웃/다른 사용자로 로그인을 선택하면 저장된 앱 계정을 지우고 다시 입력합니다. Firebase 인증 토큰/UID는 임의로 삭제하지 않습니다.
- 현지시간/한국시간을 날짜와 함께 상단에 고정했습니다. `Europe/Zagreb`, `Asia/Seoul` 시간대를 사용하며 기기 시계 기준입니다. 일정에서 선택한 날짜가 아닌 현재시간을 보여줍니다.
- 기존 날씨, 위치 ON/OFF, 데이터 사용량 표시를 유지합니다. 스크롤시 상단 정보가 사라지던 body overflow 충돌도 수정했습니다.
- 지도 명단: 조장 우선, 조별 ON/OFF·미확인 집계, 간단히/자세히 선택. ON은 기존 10분 이내 수신 기준이며, 오래된 좌표는 지연으로 표시합니다.
- 전체 메뉴 > 팀원 명부: 그룹/사람과 별도의 화면. 팀장/부팀장/총무/조장/발표를 표시합니다.
- 화장실 목록은 전체 메뉴에서만 열며 일정의 중복 목록을 제거했습니다. 장소·금액·출처·지도 데이터는 유지합니다.
- 긴급 연락: 위재복(팀장), 이상미(총무), 한상호, 나종민 교수, 여행사 인솔자. 112는 작은 바로가기로 유지했습니다.

## GitHub Pages 적용
ZIP을 풀면 `index.html`이 최상위에 있습니다. 기존과 같은 배포 경로에 `index.html`, `css`, `js`, `data`, `assets`를 함께 덮어쓰세요. 새 파일 `css/usability.css`와 `js/usability.js`도 포함해야 합니다.
스타일/스크립트 버전 문자열은 `20260919-MIX05`입니다.

## Firebase
**MIX04에서 경비·출석·위치가 작동했다면 추가 설정이 없습니다.** Rules, UID, 사람별 저장키, 데이터 경로를 바꾸지 않았습니다. 기존 데이터를 삭제하지 마세요.
공동경비는 이상미·한상호에게만 보이는 MIX04 방식을 그대로 유지합니다. 이 이름기반 간편 로그인은 서버에서 실제 신원을 검증하는 로그인은 아닙니다.
