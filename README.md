프로토타입에서는 화면 구조와 스타일만 가져왔습니다. 여행정보, 일정, 명부의 기관·직위·생년·전화번호, Google Maps/Firebase 설정은 첨부 원본에서 유지했습니다. 이번 작업에서 관광 요금·운영시간·날씨 참고값 등을 새로 조사한 것은 아닙니다.

## 달라진 화면
- 주요 메뉴: **오늘 / 일정 / 지도 / 그룹 / 더보기**
- 그룹은 **출석 / 사람** 두 탭만 사용합니다. 공지·투표 메뉴를 추가하지 않았습니다.
- 사진과 공동경비는 더보기에서 엽니다.
- 날씨는 로그인 후 모든 화면의 최상단에 고정됩니다. 가로 스크롤 속에 숨지 않습니다.
- 데이터 사용량은 상단에 계속 표시됩니다. 눌러 측정 범위를 확인할 수 있습니다.
- 좁은 화면은 1열·하단 메뉴, 중간 화면은 2열, 840 CSS px 이상은 좌측 메뉴로 바뀝니다.
- 넓은 지도 화면은 지도와 명부를 나란히 보여줍니다. 실제 위치가 공유되고 지도 버튼을 눌렀을 때 표시됩니다.
- 날짜별 일정·관광지 인라인 펼침·화장실·추천앱 등은 원본 기능을 유지합니다.

## 공동경비
더보기 → 공동경비는 위 네 운영진에게만 보입니다. 일반 조장·교수·원우에게는 노출하지 않으며 직접 경로 접근도 차단합니다.

입력: 날짜, 내용, 분류, 금액, EUR/KRW, 결제자, 메모.

참여자:
- 전체: 원우 27명 + 교수 1명 = 28명.
- 개별 선택: 이름별 또는 조별 선택/해제. 인원수를 즉시 계산합니다.
- 0명 저장은 차단합니다.
- 이름/고정ID/당시 조/인원수를 금액과 함께 같은 레코드에 저장합니다.

저장: Firebase 운영진 기기 승인을 받은 후 공유 저장. 네 운영진이 같은 기록을 조회·수정합니다. 기기 내 초안은 별도로 저장·복원합니다. 실패한 요청을 공유 완료로 표시하지 않습니다. 동시 수정 충돌은 ETag로 감지하고 덮어쓰지 않습니다.

서로 다른 통화를 섞어 합계를 내지 않습니다. 이 기능은 사용 내역과 참여자를 기록하는 기능이며 개인별 송금·채무·환율 정산을 자동으로 확정하지 않습니다.
