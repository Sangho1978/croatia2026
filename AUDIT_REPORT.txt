CROATIA2026 SPA 검증수정판 r3

1. 이번에 확인된 실제 문제
- 이전 r2의 하단 메뉴는 DOM에서 사라진 것이 아니라 CSS 충돌로 5개 버튼이 세로 5행으로 배치되었습니다.
- 고정 하단바 높이는 74px인데 2~5번째 버튼이 화면 아래로 내려가 사실상 사라져 보였습니다.
- 원인: 기존 모바일 CSS의 grid-template-columns:none!important가 새 SPA 5열 규칙을 덮어썼습니다.

2. 수정
- 로그인 후 하단바를 5열 1행 그리드로 강제하고 기존 !important를 명시적으로 덮었습니다.
- 로그인 전 하단바 숨김, 로그인 성공 후 즉시 표시, 로그아웃 시 다시 숨김 처리했습니다.
- 기존 anchor 기반 navObserver는 SPA button 메뉴에서 동작하지 않게 정리했습니다.
- router 로드시 spa-mode를 즉시 적용했습니다.
