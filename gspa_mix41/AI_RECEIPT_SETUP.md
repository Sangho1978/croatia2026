# AI 영수증 판독 설정

기존 Tesseract 기기 OCR은 백업으로 유지됩니다. 정확도를 높이려면 `backend/receipt-ai`의 Firebase Function을 배포한 뒤 `js/config.js`의 `AI_RECEIPT_ENDPOINT`에 URL을 넣으세요.

앱 동작:
1. 영수증 촬영/선택
2. AI endpoint가 있으면 AI 비전 판독 우선
3. 실패하거나 endpoint가 없으면 기기 OCR 자동 fallback
4. 날짜·시각·상호·최종 결제액·통화·분류 자동 입력
5. 사용자가 노란 입력칸을 확인/수정
6. 저장

보안: OpenAI API 키는 브라우저/GitHub에 넣지 않습니다.

## 참여자 선택
실제 사람을 사진으로 자동 식별하는 얼굴 매칭은 포함하지 않습니다. 대신 공동경비 화면의 `최근 출석명단 불러오기`로 직전 출석체크 완료자를 한 번에 선택할 수 있습니다. 조별 선택/해제도 유지됩니다.

## EUR → KRW
EUR 경비는 저장 시점에 앱이 확인한 하나은행 매매기준율을 함께 고정 저장합니다. 선택한 사용일의 환율 endpoint가 있으면 해당 날짜를 우선 조회하고, 없으면 브라우저에 저장된 가장 가까운 하나은행 고시값으로 `추정 원화`를 계산합니다. 실제 카드 청구환율과는 다를 수 있습니다.
