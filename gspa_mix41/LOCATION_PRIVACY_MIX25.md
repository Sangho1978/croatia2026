# MIX25 위치정보 개인정보 보호 변경

## 적용 내용
- 일행의 현재 위치는 최근 24시간 이내 데이터만 화면에 표시합니다.
- 24시간이 지난 현재위치 레코드는 Firebase에 남아 있더라도 앱 화면/지도에서는 표시하지 않습니다.
- 이동이력은 각 사용자 본인만 조회할 수 있도록 `locationOwners` UID 바인딩과 Firebase Rules를 추가했습니다.
- 본인 이동이력은 최근 24시간만 조회해 지도에 경로로 표시합니다.
- 위치 상세의 전화걸기 버튼과 타인의 이동이력 버튼을 제거했습니다.
- 한상호 계정에만 `전체 위치정보 리셋` 버튼을 표시합니다.
- 관리자 리셋은 전체 현재위치, 전체 이동이력, 위치 소유 바인딩을 삭제합니다.
- 리셋 시 `locationControl`에 초기화 시각을 남겨, 열려 있는 각 기기가 이를 확인하면 위치공유를 OFF하고 자동 재전송을 멈춥니다. 이후 공유는 각 사용자가 직접 다시 시작해야 합니다.

## Firebase
이 변경은 루트의 최신 `firebase.rules.json` 게시가 필요합니다.

## 보안 한계
현재 앱은 Firebase 익명 인증과 클라이언트의 이름/전화번호 끝 4자리 확인을 결합한 구조입니다. 이동이력은 Firebase UID 기준으로 본인 slot만 읽도록 제한했지만, 조직용 강한 서버 신원인증(예: Firebase Authentication의 관리 계정/Custom Claims)을 사용하는 구조는 아닙니다.
