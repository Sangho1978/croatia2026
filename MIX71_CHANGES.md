# MIX71 Changes

- Final Croatia booklet moved to a unique URL: `docs/croatia_guidebook_20261008_final.pdf`.
- Removed obsolete duplicate Croatia booklet files and old active paths.
- Guidebook cache upgraded to v71. Online opens are network-first; offline uses the latest cached final PDF.
- Schedule weather now shows daily condition, high/low, precipitation, sunrise/sunset first, followed by hourly forecast.
- Weather detail also shows sunrise/sunset and hourly forecast.
- Location OFF no longer erases the last valid position immediately. A last position under 24 hours remains visible with its timestamp/age.
- Other users' recent locations remain visible even when my sharing is OFF.
- Distance to others is calculated only when my location sharing is ON; the UI explains this requirement.
- Positions older than 24 hours are hidden.
- Croatia manifest/data and service worker bumped to MIX71.
