- 출석은 유형선택·제목·집결지 지정·필터 제거. 담당자 한상호의 시작·리셋, 참가자의 내 체크만 남김.
- 각 조 조장 먼저 표시. 완료 여부가 바뀌어도 이름의 위치가 바뀌지 않음.

- 체크는 1회. 재클릭으로 취소하지 않음. 28명이 모두 체크하면 ‘모두 확인’으로 표시.
- 리셋은 현재 회차 연결만 해제. 28명이 대기 상태로 돌아가며, 다음 시작은 새 회차 생성. 과거 출석 내역은 삭제하지 않음.

## 실시간 표시
Firebase REST EventSource의 `put/patch`를 처리합니다. 연결이 안 되면 화면이 열려 있을 때 5초 간격으로 현재 회차만 조회합니다. 토큰 갱신·화면 복귀 재연결을 처리하고 서버 시각으로 체크시간을 기록합니다. 출석용 스트림 본문도 상단 데이터량 추정에 더합니다.

오프라인/쓰기 거절은 완료로 표시하지 않습니다. 시작과 리셋에는 ETag 조건부 요청을 사용하며, 예전 회차의 늦은 체크는 새 회차 화면에 반영되지 않습니다. 실제 운영 Firebase의 Rules 검증/게시를 대신 수행한 것은 아닙니다.
